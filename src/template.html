How this page is built

Built with Claude Code from plans I wrote and reviewed. One static HTML file on Cloudflare: no framework and no cookies. The only scripts are the Email link, which copies the address, and Cloudflare's cookie-free visitor count. The words are built from my LinkedIn profile text at every deploy, and the page ships only after its browser tests pass.

  • 青海波, the wave patternDrawn by the page itself: concentric arcs, one pixel wide, tiled. A pattern Japan has used on textiles and ceramics for centuries.
  • The route, Tokyo to LondonThe experience list borrows the London line-map grammar: one line, a circle per station, a 45° turn where the city changes.

The blue is 藍, the indigo a British chemist named "Japan Blue" in the 1870s. The type is Adobe's Source family; the kanji are set in Noto Serif JP, whose Latin letters come from the same Source Serif.
